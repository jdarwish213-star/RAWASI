# RAWASI | Luxury Real Estate Website

A modern and elegant real estate website designed to showcase premium properties through a refined visual identity and a seamless user experience.

## About The Project

RAWASI is a real estate web project focused on presenting properties with a luxurious and contemporary design. The website combines a sophisticated visual style with a clean layout to create an engaging browsing experience.

## Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- Tailwind CSS
- HTML5
- CSS3
- GSAP & AOS (for animations, where implemented)

## Design & Experience

- Modern luxury-inspired visual identity.
- Elegant monochromatic color palette.
- Clean and structured user interface.
- Responsive design for different screen sizes.
- Smooth visual interactions and animations.

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/jdarwish213-star/RAWASI.git
   ```

2. Navigate to the project directory:

   ```bash
   cd RAWASI
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
